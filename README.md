# Gestão de Custos

Aplicação web responsiva para gestão de custos compartilhados.

## Publicação

O site é compilado automaticamente e publicado gratuitamente pelo GitHub Pages
a cada atualização da branch `main`.

URL: https://searomjf.github.io/gestao-de-custos/

Os dados permanecem no projeto Supabase existente. Este repositório contém
somente o cliente web e a chave pública de acesso, protegida pelas políticas RLS
do banco.
